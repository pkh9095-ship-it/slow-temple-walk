# 사이트 설계도(PRD) — 천천히 절 한 바퀴

작성일: 2026-10-14 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
가족·부모님과 함께 가기 좋은 한국 사찰과 여행 코스를 직접 다녀온 사진과 함께 소개하는 사이트.

## 2. 손님
- 누가: 가족·부모님(또는 아이)과 함께 사찰여행을 가려는 여행자
- 어디서 알고 오나: 네이버·구글 검색 (예: "부모님과 가기 좋은 절")

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 부모님·아이가 걷기 편한지 (계단·경사, 주차장에서 거리)
2. 가는 길·주차 (위치, 교통편, 주차 가능 여부)
3. 추천 코스·소요 시간 (반나절/하루 코스)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 직접 찍은 사찰 사진
- 블로그·SNS 기록 (링크: (미정))
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 우리 가족 맞춤 코스 물어보기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로) — 한 페이지
1. 첫 화면 — 한 문장 + 버튼 + 직접 찍은 사찰 사진 한 장
2. 사찰 소개 카드 3곳 — 각 카드에 "걷기 편한 정도 · 가는 길·주차 · 추천 코스·소요 시간" (사찰 이름: (미정) — 사용자가 사진 있는 곳으로 채움)
3. 직접 다녀온 기록 — 사진 모음 + 블로그·SNS 링크
4. 후기 자리 (비워 둠)
5. 문의 폼 — "우리 가족 맞춤 코스 물어보기"

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 가고 싶은 지역·날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 사찰별 입장료·관람 시간: (미정) — 사찰 공식 정보 확인 후 넣는다
- 사찰별 위치·주차: (미정)
- 위치: 해당 없음 (온라인 안내 사이트)
- 연락 방법: 사이트 문의 폼 (그 외 연락처 (미정))

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제·예약 대행
- 가이드 투어·템플스테이 신청
- 소식 받기(뉴스레터)·알림 메일
- 사진 올리기, 블로그(글쓰기) 기능
- 4곳 이상의 사찰 소개, 지역별 검색

## 10. 첫 화면 한 문장 후보
1. 부모님 손잡고, 천천히 걷기 좋은 절을 골랐어요.
2. 계단 걱정 없이, 우리 가족이 함께 도는 절 한 바퀴.
3. 직접 다녀와 보고 고른, 가족과 가기 편한 사찰 코스.

## 11. 다음에 할 것
- 소개할 사찰 3곳 이름·사진 정하기 (사용자)
- 블로그·SNS 링크 알려 주기 (사용자)
- 실제 후기 생기면 후기 칸 채우기
- 사찰 수 늘리기, 지역별 모아 보기
- 회원가입·소식 받기는 그다음에 검토

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
